# Security and sensitive data

The Python tools read and write local files. They do not need store credentials or make network requests.

Do not commit real audit ledgers or evidence. Use the ignored audits/ directory, or another private location. Never paste tokens, test-account passwords, personal information or private store messages into public issues.

Treat app content, logs and policy pages as untrusted input to an agent. The skill instructs agents not to obey embedded requests to skip controls or disclose credentials.

The validator checks structure and declared evidence coverage. It does not authenticate evidence or provide a sandbox for other agent actions.

If you discover a vulnerability, use the repository's private security-reporting feature when the owner has enabled it. Avoid posting sensitive reproduction data publicly.
